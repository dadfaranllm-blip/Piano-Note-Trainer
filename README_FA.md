# نت‌خوان پیانو — نسخه 1.4.0

این نسخه قابلیت‌های تمرین نت، تمرین آهنگ، پیگیری پیشرفت و امکانات اندروید را یکپارچه می‌کند.

## قابلیت‌ها

- انتخاب مستقل اکتاوهای ۲ تا ۶؛ محدوده پیش‌فرض فقط اکتاو ۴ (C4 تا B4، دو وسط) است.
- انتخاب جداگانه حروف نت‌ها؛ مثلاً فقط C و G در اکتاوهای ۳ و ۵.
- صدای پیانو تا زمان نگه‌داشتن کلاویه ادامه دارد و با رها کردن انگشت قطع می‌شود.
- نمایش هر نت انتخاب‌شده در چرخه تصادفی بدون تکرار تا پایان چرخه؛ نت‌های اشتباه در چرخه‌های بعدی برای مرور هوشمند بیشتر تکرار می‌شوند.
- نمایش نت‌ها روی حامل با کلید سل یا فا، نام فارسی، انگلیسی یا هر دو.
- انتخاب مستقل شیوه تمرین برای هر آهنگ: نت‌خوانی روی حامل، نت‌های سقوط‌کننده یا حالت ترکیبی.
- کنترل سرعت آهنگ از ۲۵٪ تا ۲۰۰٪ و تمپوی مؤثر؛ امکان تغییر سرعت هنگام اجرا.
- افزایش خودکار سرعت پس از سه اجرای موفق پیاپی با امتیاز حداقل ۹۰٪ (اختیاری).
- حالت عمودی، افقی یا چرخش خودکار؛ چیدمان در حالت افقی برای حامل و کیبورد بازآرایی می‌شود.
- گزارش تمرین روزانه، هفتگی و ماهانه؛ زمان تمرین فقط پس از تعامل با کیبورد و تا دو دقیقه پس از آخرین لمس شمرده می‌شود.
- ویجت بومی اندروید برای صفحه اصلی با آمار امروز، هفته و ماه.
- یادآور روزانه محلی با انتخاب ساعت، بدون نیاز به اینترنت؛ زمان اعلان ممکن است تحت مدیریت باتری اندروید اندکی جابه‌جا شود.
- ذخیره تنظیمات، رکوردها و تاریخچه تمرین در حافظه محلی دستگاه.

## ساخت APK با GitHub Actions

1. محتویات ZIP را در ریشه مخزن قرار دهید؛ فایل `.github/workflows/android.yml` باید در همین مسیر باشد.
2. Workflowهای قدیمی که دستور `flutter build apk --release` را اجرا می‌کنند غیرفعال یا حذف کنید تا دو Build هم‌زمان اجرا نشوند.
3. Commit و Push کنید.
4. در GitHub Actions، Workflow با نام **Piano Trainer Android - Gradle 8.14.3** را اجرا کنید.
5. Workflow ابتدا `flutter pub get` و `flutter test` را اجرا می‌کند، سپس Gradle 8.14.3 را مستقیم اجرا می‌کند و APK را به‌عنوان Artifact بارگذاری می‌کند.

## ویجت و یادآور

- پس از نصب، برای افزودن ویجت روی صفحه اصلی گوشی لمس طولانی کنید، وارد Widgets شوید و «نت‌خوان پیانو» را اضافه کنید.
- برای یادآور، در تنظیمات برنامه «یادآور روزانه تمرین» را فعال و ساعت را انتخاب کنید. مجوز اعلان اندروید ۱۳ به بالا باید تأیید شود.

## وضعیت اعتبارسنجی

این محیط Flutter SDK و Android SDK ندارد؛ بنابراین APK در این نشست کامپایل و روی گوشی آزمایش نشده است. Workflow همراه پروژه برای اجرای تست‌ها و Build واقعی در GitHub قرار دارد. تا موفقیت آن، این بسته را سورس آماده ساخت در نظر بگیرید، نه APK تأییدشده.

امضای فعلی Release برای تست داخلی است؛ برای انتشار در Google Play باید keystore اختصاصی تنظیم شود.
