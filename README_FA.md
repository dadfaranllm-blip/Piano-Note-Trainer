# نت‌خوان پیانو — نسخه 1.3.1

اپلیکیشن Flutter اندروید برای تمرین نت‌خوانی پیانو و تئوری موسیقی؛ بدون نیاز به اینترنت یا حساب کاربری.

## امکانات

- نمایش نت روی پنج‌خط حامل با کلید سل و فا
- نام نت‌ها به‌صورت فارسی (دو، ر، می...)، انگلیسی (C, D, E...) یا هر دو
- انتخاب نت‌های مورد تمرین، محدوده صوتی، سطح دشواری و سرعت پاسخ
- کیبورد پیانوی قابل پیمایش با کلاویه‌های سفید و سیاه و صدای تولیدشده در Android
- تمرین تک‌نت، تمرین ملودی و چهار قطعه مبتدی
- ارزیابی نت، زمان شروع و مدت نگه‌داشتن کلاویه در تمرین آهنگ؛ امتیاز نت و ریتم جداگانه محاسبه می‌شود
- تنظیم تمپو برحسب BPM و امکان خاموش کردن ارزیابی ریتم
- هشت درس مقدماتی تئوری موسیقی همراه با پرسش، پاسخ و توضیح
- تکرار هوشمند نت‌های دشوار و ذخیره آفلاین تنظیمات، خطاها، پیشرفت درس‌ها و رکورد آهنگ‌ها

## ساخت APK با GitHub Actions

این مخزن شامل سورس برنامه است، نه APK آماده. برای ساخت APK بدون نصب Flutter و Android SDK روی رایانه شخصی:

1. فایل ZIP را استخراج کنید.
2. محتویات پوشه `piano_note_trainer` را در ریشه یک مخزن GitHub بارگذاری کنید؛ پوشه `.github/workflows` نیز باید در ریشه مخزن قرار بگیرد.
3. در GitHub وارد زبانه **Actions** شوید.
4. گردش‌کار **Build Android APK** را انتخاب کنید.
5. روی **Run workflow** بزنید و اجرای آن را آغاز کنید.
6. پس از سبز شدن اجرای workflow، در پایین صفحه اجرای workflow بخش **Artifacts**، فایل `piano-note-trainer-android-v1.3.1` را دانلود کنید.
7. فایل ZIP دریافتی را استخراج کنید؛ فایل `app-release.apk` داخل آن است.

این workflow با Java 17، Flutter stable و Gradle 8.9 اجرا می‌شود. ابتدا تست‌های Flutter را اجرا می‌کند و فقط در صورت موفقیت آن‌ها APK نسخه release را می‌سازد. برای ساخت wrapper، یک پروژه موقت Flutter ایجاد می‌شود و فقط فایل‌های Gradle Wrapper به پروژه اصلی کپی می‌شوند؛ فایل اختصاصی `MainActivity.kt` و کد برنامه جایگزین نمی‌شوند.

Workflow به‌صورت خودکار با push یا pull request به شاخه‌های `main` و `master` نیز اجرا می‌شود.

## ساخت محلی

پس از نصب Flutter SDK، Android SDK و Java 17، از ریشه پروژه اجرا کنید:

```bash
flutter pub get
flutter test
```

در این بسته فایل‌های Gradle Wrapper وجود ندارد. برای ساخت محلی نیز می‌توانید ابتدا wrapper را از یک پروژه موقت Flutter ایجاد و فایل‌های آن را به `android/` کپی کنید؛ یا از GitHub Actions استفاده کنید.

خروجی مورد انتظار:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## امضای APK

پیکربندی فعلی release از امضای debug برای نصب و ارزیابی آزمایشی استفاده می‌کند. این APK برای انتشار رسمی در Google Play مناسب نیست. انتشار عمومی نیازمند ساخت keystore اختصاصی، نگهداری امن کلیدها در GitHub Secrets و تنظیم signingConfig برای release است.
